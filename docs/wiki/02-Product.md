# 02. Product Capabilities & Persona Guide

## Core Functional Capabilities
- **Line-Indexed Parsing**: Parses Markdown/PDF into line-level chunks preserving explicit line numbers.
- **Living Impact Analysis**: Generates side-by-side diff recommendations for affected downstream documents.
- **Enterprise Integrations**: Bi-directional sync with Jira, Confluence, SAP Cloud ALM, and ServiceNow ITSM.

## Personas & User Flows
- **Enterprise Architect**: Maintains canonical ontology schemas and enforces architectural decisions.
- **Software Engineer**: Visualizes dependency blast radius before committing API breaking changes.
- **Security & Compliance Auditor**: Audits AES-256 CMEK encryption and SHA-256 WORM audit logs.
